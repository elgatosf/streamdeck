### v6.4.0{#stream-deck-6-4-0}

<ul>
	<li>Added support for Node.js plugins (beta).</li>
	<li>Added `DisableAutomaticStates` option to manifest.</li>
	<li>Added `setTriggerDescription` command for Stream Deck + encoders.</li>
	<li>Added `range` to BAR layout item.</li>
	<li>Added `range` to GBAR layout item.</li>
	<li>Added `text-overflow` to TEXT layout item.</li>
	<li>Deprecated support for installing plugins using the `streamdeck://` scheme.</li>
</ul>
