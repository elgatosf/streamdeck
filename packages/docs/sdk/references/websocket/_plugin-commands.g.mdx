### SwitchToProfile{#switchtoprofile}

Switches to the profile, as distributed by the plugin, on the specified device.

NB: Plugins may only switch to profiles distributed with the plugin, as defined within the manifest, and cannot access user-defined profiles.

```ts
type SwitchToProfile = {
	context: string;
	device: string;
	event: "switchToProfile";
	payload: {
		page?: number;
		profile?: string;
	};
};
```

<ObjectMember name="context">
	<ObjectMember.Type>string</ObjectMember.Type>
	Defines the context of the command, e.g. which action instance the command is intended for.
</ObjectMember>

<ObjectMember name="device">
	<ObjectMember.Type>string</ObjectMember.Type>
	Unique identifier of the device where the profile should be set.
</ObjectMember>

<ObjectMember name="event">
	<ObjectMember.Type>"switchToProfile"</ObjectMember.Type>
	Name of the command, used to identify the request.
</ObjectMember>

<ObjectMember name="payload" >
	<ObjectMember.Type>TPayload</ObjectMember.Type>
	
Additional information supplied as part of the command.

<ObjectMember name="page" optional>
	<ObjectMember.Type>number</ObjectMember.Type>
	Optional page to show when switching to the profile, indexed from 0. When `undefined`, the page that was previously
	visible (when switching away from the profile will be made visible.
</ObjectMember>

<ObjectMember name="profile" optional>
	<ObjectMember.Type>string</ObjectMember.Type>
	
Name of the profile to switch to; the name must be identical to the one provided in the manifest.

When not specified, Stream Deck will switch to the previous profile.

</ObjectMember>

</ObjectMember>
