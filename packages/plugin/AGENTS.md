# Stream Deck SDK

`@elgato/streamdeck` is the official Node.js SDK for creating Stream Deck plugins.

The complete documentation ships with this package as Markdown, starting at the [documentation index](./docs/index.md). It includes getting started guides, plugin guides (actions, keys, dials, settings, property inspectors, devices, and more), style guides, and references for the manifest, layouts, and the WebSocket API.

Historical documentation for previous major versions is available in [`docs/v2`](./docs/v2/index.md) and [`docs/v1`](./docs/v1/index.md); prefer the latest documentation unless working with an older version of the SDK.
