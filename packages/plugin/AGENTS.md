# Stream Deck SDK

`@elgato/streamdeck` is the official Node.js SDK for creating Stream Deck plugins.

The complete documentation ships with this package in [`docs/`](./docs/), starting with [getting started](./docs/introduction/getting-started.mdx). Guides cover each feature in [`docs/guides/`](./docs/guides/), and the manifest, layouts, and WebSocket API are documented in [`docs/references/`](./docs/references/).
