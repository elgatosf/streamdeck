# Distribution

In this article you'll learn about preparing and packaging your plugin ready for publishing on Marketplace.

## Overview

Plugins are packaged into `.streamDeckPlugin` files using the [Stream Deck CLI](../../docs/streamdeck/cli/intro.mdx), and once packaged, contain everything your plugin needs to be distributed on Marketplace, or directly to users.

## DRM Protection

Plugins distributed on Marketplace are eligible for DRM (Digital Rights Management), providing you and your intellectual property with an extra level of protection.

Benefits on DRM protection also include:

- **File Encryption** — Prevent unauthorized vendors from executing your plugin without your consent.
- **Integrity Checking** — Protect users from tampered files, with built-in file integrity verification.
- **New SDK Features** — Unlock new Stream Deck SDK features.

<Info>

Plugins created with Stream Deck CLI 1.6 or higher have DRM enabled as default; to check your CLI version run `streamdeck -v`, and update by running:

```bash title="Update Stream Deck CLI"
npm install -g @elgato/cli@latest
```

</Info>

### Compatibility & Readiness

The following set of criteria are pre-requisites for DRM protection, and it is important they are reviewed before enabling DRM protection.

**Node.js SDK** — Node.js plugins must be using `@elgato/streamdeck` v2 or higher. [Learn more](../upgrading/v2.mdx).

**File Integrity** — Files distributed in your plugin are immutable.

<GoodBadList>
	<Good required>Generate required files at runtime.</Good>
	<Bad required>Modify files after they have been distributed in your plugin.</Bad>
</GoodBadList>

**Manifest** — Your plugin's manifest is a protected asset.

<GoodBadList>
	<Good required>
		Include a separate JSON file, or embed directly into your codebase, additionally required non-sensitive information.
	</Good>
	<Bad required>Access the manifest JSON file at runtime.</Bad>
</GoodBadList>

<Warning title="tl;dr">

- Node.js plugins must be using `@elgato/streamdeck` v2 or higher.
- Files distributed with your plugin are immutable.
- Your plugin's manifest cannot be accessed at runtime.

</Warning>

<Tip title="SDK compatibility">
	DRM protection is available to all Stream Deck SDK libraries, such as C#, C++, and Go, and is not limited to Node.js.
</Tip>

### Enabling DRM

After reviewing compatibility, to enable DRM:

1. Update to `@elgato/streamdeck` v2 or higher (Node.js plugins only). [Learn more](../upgrading/v2.mdx).
2. In your manifest
   1. Set [`UUID`](../references/manifest.mdx#manifest-uuid) to your plugin's identifier, e.g. `com.elgato.wave-link`.
   2. Update [`SDKVersion`](../references/manifest.mdx#manifest-sdkversion) to be `3`.
   3. Update [`Software.MinimumVersion`](../references/manifest.mdx#software-minimumversion) to be `"6.9"` or higher.

<Danger title="Caution">
	Plugins with DRM enabled are only protected **after** they have been uploaded and processed in Maker Console. [Learn
	more about accessing a DRM protected version of your plugin](#testing-with-drm).
</Danger>

### Testing with DRM

Plugins with DRM enabled are only protected **after** they have been uploaded and processed in Maker Console.

On occasion, you may need to access the DRM protected version of your plugin before publishing it to users, for example when you want to:

- Distribute a beta version to testers.
- Test your plugin is DRM compatible.

To prepare and access a DRM protected version of your plugin.

1. Log in to [Maker Console](https://maker.elgato.com).
1. Upload your plugin, with "Publish after review" unselected.
1. Navigate to your product's page in Maker Console.
1. Select the "Versions" tab.
1. Select the new version of your plugin.
1. Download the DRM protected version.

## Packaging

When your plugin is ready for distribution, you can package it into a `.streamDeckPlugin` installer file using the Stream Deck CLI's [`pack`](../../docs/streamdeck/cli/commands/pack.mdx) command.

```bash title="Example of packaging a plugin"
# Pack the *.sdPlugin directory
streamdeck pack com.elgato.hello-world.sdPlugin
```

Running the `pack` command does the following

1. Validates your plugin and supporting files.
   - See also [`validate`](../../docs/streamdeck/cli/commands/validate.mdx).
2. Bundles the contents of the `*.sdPlugin` directory.
3. Outputs the `.streamDeckPlugin` installer file.

<Tip title="Ignoring files">
	When packaging your plugin, you can ignore files by specifying paths, using `.gitignore` specification, within a
	`.sdignore` file. [Learn more about ignoring files when
	packaging](../../docs/streamdeck/cli/commands/pack.mdx#description).
</Tip>

## Publishing

Marketplace provides a platform for your plugin, and allows you to reach millions of Stream Deck users by making your plugin discoverable within the catalog of Stream Deck plugins.

<figure>
	[<img src="/img/badges/get-it-on-marketplace--dark.svg" height="54px" alt="Get it on Marketplace" />
	](https://marketplace.elgato.com/stream-deck/plugins)
</figure>

To publish on Marketplace, you should follow these steps:

1. [Review plugin guidelines](../../docs/sync/7jPsXtEDoon2S42hbRbXek.mdx) — Make sure your plugin conforms to Stream Deck and Marketplace style guidelines.
2. [Create an app icon](../../docs/sync/5hdKZvVI2mGQmqvLnUy7hi.mdx) — Create an eye-catching app icon.
3. [Create gallery items](../../docs/sync/5hdKZvVI2mGQmqvLnUy7hi.mdx) — Showcase your plugins functionality.
4. [Submit for review](https://maker.elgato.com) — Submit, manage, and review your products using Maker Console.

You can also learn more about submitting products to Marketplace in [Become a Maker](../../docs/sync/7MpNh5rCKQiHHrVLkJ7cWh.mdx).

<Info title="Returning Makers">
	Returning Maker? After creating an account within Maker Console, if you are unable to see your plugins, please contact
	our Maker Relations team on maker@elgato.com.
</Info>
